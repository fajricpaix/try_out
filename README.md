## Android USB Workflow

Use helper script below to run from this project with Android SDK environment already set:

```bash
scripts/android_dev.sh devices
scripts/android_dev.sh run
```

While `run` is active:

- Press `r` for hot reload
- Press `R` for hot restart

Useful diagnostics:

```bash
scripts/android_dev.sh doctor
scripts/android_dev.sh logs
```
